# Design a Go solution

Use the `go-solution-design` and `go-bootstrap` skills.

1. Clarify whether this is a library, CLI, server, or mixed module.
2. Propose a layout from go.dev/doc/modules/layout and draw it.
3. Sketch APIs for additive evolution; call out any unavoidable breaks.
4. Define cancellation, error and test strategies up front.
